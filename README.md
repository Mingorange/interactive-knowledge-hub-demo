# Interactive Knowledge Hub — Demo 互动知识馆（演示版）

Middle-school knowledge points, rebuilt as **interactive, isometric illustrated web pages**.

把中学知识点，做成可交互的等距图解网页。

## Why / 理念

A textbook or PDF can show a diagram, but it is static. What a student actually struggles with is usually a **process**: a colour changing during a reaction, an image forming through a lens, a curve reshaping as a coefficient moves.

> What a PDF cannot do — **interaction + watching a process change** — is exactly what these pages do.
>
> PDF 做不到的「互动 + 变化过程」，就是这个项目的价值。

In chemistry pages, **colour change is the first narrative line**: every stage's colour is shown big and labelled clearly, so the change itself teaches the concept.

化学页的第一叙事线是颜色变化：每个阶段的颜色都大面积呈现、狠标注，让「变化」本身来讲课。
